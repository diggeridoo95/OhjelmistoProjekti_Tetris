2. BOMB ABILITY DISPLAY - VISUAL IMPROVEMENT
================================================================================

PURPOSE: 
When the bomb ability is available, shows a visual preview of the bomb block
in the ability rectangle (similar to the Next block preview). When no ability
is available, shows "No Ability" text.

FILES MODIFIED:
- main.py (UI drawing code)

---

CHANGE 2.1: Replace text-only ability display with block preview
Location: main.py, lines 250-275

BEFORE:
    # Display ability status
    if game.has_bomb:
        ability_text = "Bomb: Available" if not game.bomb_active else "Bomb: Active"
        ability_color = Colors.white if not game.bomb_active else (255, 255, 0)
    else:
        ability_text = " "
        ability_color = Colors.white
    
    ability_value_surface = small_font.render(ability_text, True, ability_color)
    screen.blit(ability_value_surface, ability_value_surface.get_rect(centerx = ability_rect.centerx, 
                                                                       centery = ability_rect.centery))

AFTER:
    # Display ability status
    if game.has_bomb:
        # Draw a bomb block preview in the ability rect
        bomb_block = BombBlock()
        bomb_block.cell_size = layout["cell_size"]
        tiles = bomb_block.get_cell_positions()
        if tiles:
            min_col = min(tile.column for tile in tiles)
            max_col = max(tile.column for tile in tiles)
            min_row = min(tile.row for tile in tiles)
            max_row = max(tile.row for tile in tiles)
            
            tile_size = bomb_block.cell_size
            shape_width = (max_col - min_col + 1) * tile_size
            shape_height = (max_row - min_row + 1) * tile_size
            
            offset_x = ability_rect.x + (ability_rect.width - shape_width) // 2 - (min_col * tile_size)
            offset_y = ability_rect.y + (ability_rect.height - shape_height) // 2 - (min_row * tile_size)
            bomb_block.draw(screen, offset_x, offset_y)
    else:
        # Show "No Ability" text when bomb is not available
        ability_text = "No Ability"
        ability_color = Colors.white
        ability_value_surface = small_font.render(ability_text, True, ability_color)
        screen.blit(ability_value_surface, ability_value_surface.get_rect(centerx = ability_rect.centerx, 
                                                                           centery = ability_rect.centery))

How It Works:
1. Checks if bomb ability is available via game.has_bomb boolean
2. If available:
   - Creates a temporary BombBlock instance
   - Sets its cell_size to match current layout
   - Gets the block's tile positions (for a bomb block, just one tile)
   - Calculates the bounding box of all tiles
   - Calculates offsets to center the block in the ability_rect
   - Calls bomb_block.draw() which renders the custom bomb graphics
3. If not available:
   - Renders "No Ability" text in the center of the rect

Dependencies:
- game.has_bomb: boolean from game.py (set to True when row is cleared)
- BombBlock: imported from blocks.py
- layout["cell_size"]: current cell size from the layout system
- ability_rect: coordinates of the ability display area (defined line 199)

Visual Result:
- When ability active: Shows the bomb block with custom pixel-art styling
  (dark circle body, brown fuse, orange spark pixels)
- When no ability: Shows plain text saying "No Ability"
- Matches the styling of the "Next" block preview area

3. TECHNICAL TIMELINE - WHEN THINGS TRIGGER
================================================================================

NORMAL GAMEPLAY FLOW:

Start Game → Wait 10 seconds
    ↓
[INVERSION TRIGGER] on next block spawn
    ├─→ inversion_flash_effect.trigger() [ACTIVATION FLASH]
    ├─→ Grid flips vertically
    └─→ Gravity reverses (blocks fall upward)

[PLAY FOR ~3 MORE BLOCKS with inverted gravity]
    ↓
3rd block locks during inverted gravity
    ├─→ inversion_flash_effect.trigger() [DEACTIVATION FLASH]
    ├─→ Grid flips back to normal
    └─→ Gravity returns to normal (blocks fall downward)

BOMB ABILITY FLOW:

Clear 1+ row
    ├─→ game.has_bomb = True
    ├─→ Ability rect shows bomb block preview
    └─→ Player can press 'A' key to use it

Press 'A' key
    ├─→ next_block replaced with BombBlock
    └─→ Block preview shows bomb

Place bomb block on playfield
    ├─→ Bomb explodes in 13-cell cross pattern
    ├─→ BombExplosionEffect animation plays
    └─→ game.has_bomb = False
        └─→ Ability rect shows "No Ability" again

5. ANIMATION SPECIFICATIONS
================================================================================

INVERSION FLASH EFFECT:
- Duration: 500 milliseconds (0.5 seconds)
- Color: RGB(150, 100, 255) = Cyan/Purple
- Alpha: Starts at 180, fades to 0
- Coverage: Full-screen overlay
- Easing: Linear fade-out
- Triggered: When gravity inverts (2 times per cycle)
  * Once on activation
  * Once on deactivation

BOMB BLOCK PREVIEW:
- Display Type: Block graphic (not text)
- Graphics: Custom pixel-art bomb icon
  * Body: Dark circle (40% of cell radius)
  * Fuse: Brown line
  * Spark: Orange/yellow pixels
- Positioning: Centered in ability_rect
- Size: Scales with current game layout cell_size
- Fallback Text: "No Ability" when not available
